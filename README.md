## The scene

## How it works

`main.py` (Python 3, standard library only) writes the short family scene to `/output/entry.txt`, self-checking the gate first: 1–280 UTF-8 characters, not only whitespace, one or two lines.

```sh
python3 main.py
cat /output/entry.txt
```
